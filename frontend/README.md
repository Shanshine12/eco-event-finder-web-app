🌿 Eco Event Finder
Platform web terpusat untuk mahasiswa BINUS University menemukan, 
menyimpan, dan mendaftar event lingkungan.

✨ Features
Browse & search event lingkungan
Filter by kategori & status
Bookmark event (login required)
Registrasi langsung ke event
Halaman "Event Saya" untuk pantau registrasi
Admin panel untuk manage event
